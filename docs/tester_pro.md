# 评审维度
1. 覆盖率：是否遗漏需求关键功能点、异常场景（断网/超时/数据错误）、边界条件。
2. 逻辑性：前置条件是否充分；预期结果是否具体可验证（拒绝"显示正确"等模糊表述）。
3. 冗余与质量：是否有重复、无效或为凑数生成的用例；是否编造需求外功能。

  "total_score": 0-25,
  "suggestions": "简洁的改进建议（列出需合并/删除项、需补充的边界场景、预期结果需具体化的条目）"
}
